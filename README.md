# Tarjeta DG | Modelo de caja CSS

Proyecto desarrollado para Generation como práctica de CSS, en el que creé una tarjeta personal utilizando el **modelo de caja (Box Model)**.

La tarjeta incluye información ficticia y una foto de mi persona ;)

## 🌐 Demo

🔗 https://tarjeta-michalle-modelocaja.netlify.app

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## 📚 Conceptos practicados

* Modelo de caja (Box Model).
* Márgenes (`margin`).
* Relleno interno (`padding`).
* Bordes (`border`).
* Dimensiones de los elementos (`width` y `height`).
* Organización y presentación de elementos HTML con CSS.
